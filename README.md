# Ahuora agent plugins

Install this repository as a marketplace, then select the environment you need.

## Codex

```sh
codex plugin marketplace add waikato-ahuora-smart-energy-systems/ahuora-agent-plugins
codex plugin add ahuora@ahuora
codex plugin add ahuora-staging@ahuora
```

## Claude Code

```sh
claude plugin marketplace add waikato-ahuora-smart-energy-systems/ahuora-agent-plugins
claude plugin install ahuora@ahuora
claude plugin install ahuora-staging@ahuora
```
